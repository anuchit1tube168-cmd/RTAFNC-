# AGIS CORE V2 — SHARED PROTOCOL

## Purpose
This is the shared operating contract for the 12 designed Core Agents.

## Non-negotiable
Quality > agent count. Evidence > confidence. Truth > appearance.

## Core loop
DO THE MATH → FIND CONSTRAINT → SELECT SMALLEST SUFFICIENT TEAM → EXECUTE → TEST → REVIEW → EVIDENCE → LEARN

## Agent creation
New permanent Agents are not created for a new topic/tool/source.
Use:
CAPABILITY GAP → CORE + SKILL/TOOL/CONTEXT → MEASURE → SANDBOX CANDIDATE → A/B EVAL → PROMOTE / MERGE / REJECT / RETIRE.

## Scout
Scout is a RESEARCH-owned process, not automatically a new Agent.
SOURCE → SIGNAL → CLAIM CLASSIFICATION → EVIDENCE → R&D/JOB/EVAL/WATCH → OUTCOME FEEDBACK.

## R&D
R&D is a process:
RESEARCH gathers/frames hypotheses.
ARCHITECT designs technical experiments.
QA/EVAL validates independently.
LEARNING COACH promotes only proven reusable learning.

## Runtime states
READY / WORKING / REVIEW / LEARNING / BLOCKED

State must be truthful and backed by current work/evidence.

## Data boundary
Do not put real student, health, military-sensitive, customer-secret, passwords or tokens in public GitHub demo files.

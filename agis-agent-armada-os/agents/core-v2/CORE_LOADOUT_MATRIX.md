## Skill upgrade policy
Upgrade an Agent only when a real job produces evidence.

Upgrade order:
1. Better context/data
2. Better eval
3. Better checklist/skill
4. Better tool/integration
5. Better routing/memory
6. Only then specialist Agent candidate

## Level meaning
- L1 — can follow defined template under review
- L2 — can complete routine scoped jobs
- L3 — independent within bounded domain
- L4 — handles ambiguous domain work + improves methods
- L5 — orchestration/strategy responsibility with evidence discipline

Level is not prestige. It represents demonstrated operating scope.
